# 3장 - OpenCV 자료구조와 픽셀 다루기

Point/Size/Rect로 좌표와 도형 영역을 계산하고, Vec/Scalar로 색상을 표현하며, Mat을 생성·초기화하는 OpenCV 4의 기본 자료형 클래스를 익힙니다. 특히 3-4장에서는 Mat이 대입 시 데이터를 공유하는 얕은 복사와, 메모리를 새로 복사하는 깊은 복사의 장단점을 직접 비교해보았습니다. 이어서 Mat::at으로 픽셀 하나하나에 접근해 격자·포물선 그래프를 그려보고, 행렬 연산으로 영상의 속성을 확인하거나 방정식을 풀고 밝기를 조절하는 등 OpenCV의 핵심 자료구조를 손에 익히는 데 집중했습니다.

## 3-1장 - Point, Size, Rect

OpenCV 4의 기본 자료형 클래스(Point, Size, Rect 등)를 다루는 3장 도입부로, 두 점 사이의 거리 계산, 사각형 넓이 계산, Rect::contains와 Point::inside를 이용한 좌표 포함 판정, format으로 파일명을 생성하는 실습입니다.

## 3-4장 - 얕은 복사 / 깊은 복사

얕은 복사(Shallow Copy: 메모리 주소만 복사해 속도가 빠르고 메모리를 절약하지만 원본 데이터가 함께 바뀌는 부작용과 댕글링 포인터 위험이 있음)와 깊은 복사(Deep Copy: 새 메모리에 데이터를 통째로 복사해 독립적이고 안전하지만 속도가 느리고 메모리 사용량이 늘어남)의 장단점을 비교하고, Mat의 복사 방식과 ROI 활용을 실습합니다(21년 중간고사 문제 포함, 일부 결과는 동영상으로 제출).
