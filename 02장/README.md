# 2장 - OpenCV 개발환경과 첫 프로그램

OpenCV로 개발된 실제 제품 사례와 라이브러리·오픈소스 SW의 개념부터, 비주얼 스튜디오에서 Debug/Release, x86/x64, 포함/라이브러리 디렉토리, 링커 종속성, DLL PATH를 설정하는 프로젝트 구성까지 다룹니다. 이렇게 구성한 환경으로 imread/imshow로 자신의 사진을 출력하는 첫 프로그램을 작성하고, 이후 그레이스케일 변환·밝기 조절·imwrite 저장, 여러 영상을 순환 출력하는 초시계 만들기 등 실제 영상 입출력 실습으로 이어집니다.

## 2-1장 - OpenCV 소개 및 개발환경 구축

OpenCV로 개발된 제품 사례(테슬라 오토파일럷의 차선 인식·객체 감지, 스노우 앱의 얼굴 인식 필터, 스마트 공장 불량 검사, 얼굴 인식 CCTV, X-ray 의료 영상 분석)를 조사하고, 라이브러리(재사용 가능한 코드 집합, 정적/동적 라이브러리 구분)와 오픈소스의 개념, 시스템 환경변수 PATH, 컴파일 단계, 정적/동적 라이브러리의 차이를 정리한 장입니다.

## 2-2장 - 프로젝트 설정

비주얼 스튜디오에서 Debug(최적화 없이 PDB 포함)/Release(최적화 수행) 모드, x86(32비트)/x64(64비트) 모드의 차이를 설명하고, 외부 라이브러리 헤더를 찾기 위한 포함 디렉토리, 링커가 라이브러리 파일을 찾기 위한 라이브러리 디렉토리·추가 종속성 설정, OpenCV DLL 실행을 위한 PATH 환경변수 설정(C:\opencv\build\x64\vc15\bin) 방법을 다룹니다. 이를 바탕으로 imread/imshow로 자신의 사진을 불러와 출력하는 첫 영상 출력 프로그램을 작성합니다.

## 2-3장 - 영상 입출력

그레이스케일 변환과 밝기 조절 후 imwrite로 저장하기, 여러 영상을 순환 출력하기, 숫자 이미지로 카운트 초시계를 만드는 실습입니다. (과제 자체는 코드와 실행 결과 동영상으로 제출되어 있습니다.)
