# OpenCV-Practice

컴퓨터 비전 및 머신러닝 수업(2025년 1학기, "자율주행 SW(1)")에서 진행한 OpenCV C++ 실습 과제 정리 저장소입니다.

## 배운 것 / 깨달은 것 / 성취한 것

자율주행 조사와 영상처리 개념부터 시작해서 OpenCV 개발환경 구축, Point/Size/Rect 같은 기본 자료구조, 얕은 복사와 깊은 복사, 픽셀 단위 접근, 카메라·동영상 처리, 마우스/키보드 이벤트, 트랙바까지 전체 챕터를 거쳐오면서, 가장 크게 늘었다고 느낀 건 "이론으로 아는 것"과 "코드로 직접 다뤄봐야 아는 것" 사이의 간극이었습니다. 특히 3-4장 얕은 복사/깊은 복사 실습에서 Mat 객체를 대입 연산자로 복사했다고 생각했는데 원본 영상까지 같이 바뀌는 걸 보고서야 Mat이 기본적으로 데이터를 공유하는 헤더 구조라는 걸 체감했고, clone()이나 copyTo()를 명시적으로 써야 진짜 복사가 된다는 걸 실수를 통해 배운 게 가장 큰 성취였습니다. 3-5장에서 Mat::at<uchar>(), Mat::at<Vec3b>()로 픽셀 하나하나에 접근해 격자와 포물선 그래프를 그려보면서는 영상 처리가 결국 반복문으로 픽셀 좌표를 순회하는 작업이라는 걸 손으로 확인했고, 4-1장·4-2장에서 VideoCapture와 VideoWriter로 웹캠을 열고 동영상을 저장해보면서는 실시간으로 들어오는 프레임을 waitKey()로 어떻게 제어하느냐에 따라 결과가 완전히 달라진다는 걸 알게 됐습니다. 4-4장 마우스 콜백(setMouseCallback) 실습에서는 이벤트가 들어올 때마다 상태(state)를 어떻게 갱신하고 유지할지 신경 쓰지 않으면 클릭 한 번에도 프로그램이 이상하게 동작한다는 걸 직접 겪었고, 2-1장·2-2장에서 포함 디렉토리와 링커 종속성을 설정하며 헤더를 include하는 것과 라이브러리가 실제로 링크되어 실행되는 것은 완전히 다른 단계라는 것도 이 과정에서 함께 깨달았습니다.
전체적으로 OpenCV를 배운다는 건 함수 몇 개를 외우는 게 아니라, Mat이라는 자료구조가 메모리를 어떻게 다루는지, 영상이 어떻게 픽셀 단위로 흘러가는지를 직접 눈과 손으로 확인해나가는 과정이었다는 걸 챕터를 거듭할수록 깨달았습니다.

### 1장 - 영상처리와 컴퓨터 비전
컴퓨터 비전 관련 제품을 조사해보고, 영상처리(Image Processing)와 컴퓨터 비전(Computer Vision)이 어떻게 다른지, 카메라의 CMOS 이미지 센서는 어떤 원리로 동작하는지를 정리한 장입니다.

### 2장 - OpenCV 개발환경과 첫 프로그램
OpenCV와 라이브러리·오픈소스 SW의 개념부터, 비주얼 스튜디오에서 포함/라이브러리 디렉토리·링커 종속성·DLL PATH를 설정하는 프로젝트 구성까지 다룹니다. 여기서 배운 환경설정을 바탕으로 imread/imshow로 첫 영상 출력 프로그램을 작성하고, 이후 그레이스케일 변환·밝기 조절·imwrite 저장, 여러 영상을 순환 출력하는 초시계 만들기 등 실제 영상 입출력 실습으로 이어집니다.

📁 [2장/](./02장/)

### 3장 - OpenCV 자료구조와 픽셀 다루기
Point/Size/Rect로 좌표와 도형 영역을 계산하고, Vec/Scalar로 색상을 표현하며, Mat을 생성·초기화하고 얕은 복사와 깊은 복사의 차이를 실습을 통해 겪어보는 장입니다. 이어서 Mat::at으로 픽셀 하나하나에 접근해 격자·그래프를 그려보고, 행렬 연산으로 영상의 속성을 확인하거나 밝기를 조절하는 등 OpenCV의 핵심 자료구조를 손에 익히는 데 집중했습니다.

📁 [3장/](./03장/)

### 4장 - 카메라, 그리기, 이벤트 처리
웹캠으로 영상을 캡처하고 동영상 코덱을 이용해 저장하는 카메라·동영상 처리부터 시작해서, line/rectangle/circle/putText 같은 그리기 함수로 초시계와 버튼을 구현하고, 마우스·키보드 이벤트와 트랙바로 사용자 입력에 반응하는 프로그램을 만들어보는 장입니다.
