# 2-2장 - 프로젝트 설정

비주얼 스튜디오에서 Debug(최적화 없이 PDB 포함)/Release(최적화 수행) 모드, x86(32비트)/x64(64비트) 모드의 차이를 설명하고, 외부 라이브러리 헤더를 찾기 위한 포함 디렉토리, 링커가 라이브러리 파일을 찾기 위한 라이브러리 디렉토리·추가 종속성 설정, OpenCV DLL 실행을 위한 PATH 환경변수 설정(C:\opencv\build\x64\vc15\bin) 방법을 다룹니다. 이를 바탕으로 imread/imshow로 자신의 사진을 불러와 출력하는 첫 영상 출력 프로그램을 작성합니다.
