# 4장 - 카메라, 그리기, 이벤트 처리

카메라·동영상 관련 API(V4L, FFmpeg, DirectShow, MSMF, GStreamer)와 압축 코덱(MPEG-4, H.264, H.265 등)을 조사한 뒤, VideoCapture/VideoWriter로 웹캠 영상을 캡처하고 저장하는 실습부터 시작합니다. 이어서 line/rectangle/circle/putText 같은 그리기 함수로 초시계와 버튼을 구현하고, setMouseCallback과 트랙바로 마우스·키보드 입력 및 사용자 조작에 실시간으로 반응하는 프로그램을 만들어보는 장입니다.

## 4-1장 - 카메라와 동영상 처리

카메라를 제어하는 API들(운영체제·장치 제조사가 제공하는 카메라 API, 리눅스의 V4L, 오픈소스 멀티미디어 프레임워크 FFmpeg, 윈도우의 DirectShow·MSMF, 크로스플랫폼 GStreamer)을 비교 조사하고, VideoCapture로 웹캠을 열어 프레임을 캡처·저장하고 십자선을 그리는 실습입니다.

## 4-2장 - 동영상 코덱과 저장

동영상 압축 코덱(MPEG-4, DivX, 오픈소스 대안인 Xvid, 현재 가장 널리 쓰이는 H.264/AVC, 4K·8K에 최적화된 H.265/HEVC)의 특징을 비교 조사하고, VideoWriter로 밝기를 처리한 동영상을 저장하거나 웹캠 화면에 라인을 그리며 녹화하는 실습입니다(결과는 동영상 파일로 제출).
