# 1장 - 영상처리와 컴퓨터 비전

컴퓨터 비전 기술이 적용된 제품으로 테슬라의 Face ID를 예로 들어 도트 프로젝터·적외선 카메라로 3D 얼굴 맵을 생성하고 뉴럴 엔진으로 템플릿을 만들어 인증하는 동작 원리를 조사했습니다. 이어서 영상처리(주어진 영상을 변형해 품질을 개선)와 컴퓨터 비전(변형된 영상에서 의미 있는 정보를 추출)의 차이를 설명하고, CMOS 이미지 센서가 광다이오드로 빛을 전기 신호로 바꾸고 픽셀별 트랜지스터로 신호를 증폭·전송한 뒤 ADC로 디지털 신호로 변환하는 원리를 정리했습니다.
