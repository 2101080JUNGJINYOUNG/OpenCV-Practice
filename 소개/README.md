# 소개 - 자율주행과 컴퓨터 비전

현재 시험 운행 중인 자율주행 자동차(웨이모, 테슬라 오토파일럿/FSD, 모빌아이, Cruise, Zoox)를 조사하고, 자율주행을 이루는 3대 요소기술인 인지(카메라·LiDAR·레이더로 주변을 감지해 3D 맵을 생성)·판단(경로 계획과 상황 분석을 통한 의사결정)·제어(가속·브레이크·조향을 실시간 조정) 기술을 정리했습니다. 이어서 Apollo, Autoware, Openpilot, CARLA, ROS, LiDAR 기반 SLAM, TensorFlow/PyTorch, Fast-DDS 등 자율주행 관련 오픈소스 SW를 조사한 도입부입니다.
